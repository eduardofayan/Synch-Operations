# CONTEXTO GERAL

Estou desenvolvendo uma plataforma chamada Synch Operations.

A Synch Operations é uma plataforma de Operações Digitais para automação, integração de sistemas, analytics e inteligência artificial.

O ecossistema possui três produtos:

1. AutoSynch Bot
2. Synch Automation Hub
3. Synch Insight

# PRODUTOS

## AutoSynch Bot

Motor de execução.

Responsável por:

- Executar automações Python
- Executar ETL
- Executar ELT
- Executar integrações
- Processar e-mails
- Processar arquivos
- Executar RPAs
- Executar OCR
- Executar tarefas agendadas
- Executar tarefas sob demanda

O AutoSynch Bot roda dentro do ambiente do cliente.

A ideia é que ele seja instalado como Serviço Windows e execute em segundo plano.

Não queremos depender de VS Code aberto nem terminal aberto.

Fluxo desejado:

Windows inicia
↓
AutoSynch Agent inicia
↓
Conecta ao Synch Automation Hub
↓
Recebe trabalhos
↓
Executa automações
↓
Reporta resultados

Atualmente já existe um Worker funcionando.

Estrutura:

apps/autosynch-bot/

app/
├── agent/
│   └── worker.py
│
└── main.py

worker.py:

import time

class Worker:

    def __init__(self):
        self.running = True

    def start(self):

        print("AutoSynch Agent iniciado")

        while self.running:

            print("Buscando trabalhos...")

            time.sleep(30)

    def stop(self):
        self.running = False

main.py:

from app.agent.worker import Worker

def main():

    worker = Worker()

    worker.start()

if __name__ == "__main__":
    main()

Validação realizada:

python -m app.main

Saída:

AutoSynch Agent iniciado
Buscando trabalhos...

Funcionando corretamente.

Responsável por:
